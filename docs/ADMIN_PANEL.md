# Admin Panel — Full-Screen Redesign

> Админ-панель Cosmogram переработана в полноэкранный интерфейс с вкладками для удобного управления медиа.

---

## 📐 Что изменилось

- **Полноэкранный режим** — панель открывается на 100vw × 100vh, не ограничена 800px
- **Табы** — три вкладки: **Folders**, **Queue**, **Actions**
- **Поиск папок** — фильтрация списка папок по названию
- **Превью файлов** — просмотр фото/видео перед импортом прямо в панели
- **Action cards** — быстрые действия в виде карточек (очистка очереди, создание тестового поста)
- **Закрытие** — кнопка ✕ в правом верхнем углу

---

## 🎯 Как использовать

### 1. Вход
- Войдите под учётной записью **admin**
- В шапке появится кнопка ⚙️

### 2. Tab: Folders
- Показывает все доступные папки из `/opt/media/files/`
- **Поле поиска** — фильтрует папки по имени в реальном времени
- **Scan** — сканировать папку (добавить файлы в очередь)
- **Preview** — открыть превью-галерею файлов в папке
- **Import All** — импортировать все отсканированные файлы

### 3. Tab: Queue
- Статус очереди импорта: Total, Pending, Done, Errors
- Кнопка **Refresh** для обновления статуса

### 4. Tab: Actions
- **Clear Import Queue** — очистить очередь (с подтверждением)
- **Create Test Post** — создать тестовый пост с видео для проверки

---

## 🧩 Технические детали

### API Endpoints

```
GET    /api/admin/media/sources      — список папок
POST   /api/admin/media/scan         — сканировать папку
POST   /api/admin/media/import       — импортировать
GET    /api/admin/media/queue        — статус очереди
DELETE /api/admin/media/queue        — очистить очередь
GET    /api/admin/media/preview      — превью файлов в папке
POST   /api/admin/test-post          — создать тестовый пост
```

### Безопасность
- ✅ Только admin роль (middleware `requireAdmin`)
- ✅ JWT проверка на каждом запросе
- ✅ Старый CLI скрипт отключён
- ✅ Нет автоматического импорта — только ручной
- ✅ Проверка длительности видео перед импортом (мин. 1 сек)

---

## ⚠️ Замечания

1. **Scan → Import** — всегда сначала делайте Scan, потом Import
2. **Preview** — показывает файлы, уже имеющиеся в базе (не требует сканирования)
3. **Видео короче 1 сек** — отклоняются при импорте
4. Для просмотра превью используется `/api/admin/media/preview?folder=...`
