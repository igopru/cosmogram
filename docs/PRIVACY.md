# Приватность и профили пользователей

## Профили пользователей

Каждый пользователь имеет публичный профиль:

- Открывается кликом по **имени пользователя** в любом посте
- Или по кнопке 👤 в шапке (свой профиль)

В профиле видно:

- Аватар, никнейм (@username), полное имя, био
- Статистику: постов / подписчиков / подписок
- Сетку постов с превью (клик по превью открывает полный пост)
- Кнопку **+ Follow** (для чужих профилей)

### API

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/api/users/:id` | Профиль: информация, статистика, посты (с учётом видимости) |
| `GET` | `/api/users/me/access` | Мои подписчики и их статус доступа к приватным постам |
| `POST` | `/api/users/me/access/:viewerId` | Выдать доступ к приватным постам |
| `DELETE` | `/api/users/me/access/:viewerId` | Отозвать доступ |

`GET /api/users/:id` возвращает:

```json
{
  "user": { "id": 3, "username": "igor", "fullname": "...", "bio": "...", "role": "user" },
  "stats": { "posts_count": 43, "followers_count": 12, "following_count": 5, "private_posts_count": 3 },
  "is_self": false,
  "is_following": true,
  "viewer_has_access": true,
  "posts": [ /* посты, видимые текущему пользователю */ ]
}
```

## Приватные посты (семейные фото)

Любой пост можно сделать приватным (переключатель **Public/Private** в модалке создания поста).
Приватный пост видят **только**:

1. Автор поста
2. Администратор
3. Подписчики, которым автор **вручную выдал доступ**

### Как выдать доступ

1. Откройте свой профиль (👤 в шапке)
2. Нажмите **🔒 Manage private access**
3. Откроется список ваших подписчиков
4. Напротив каждого — переключатель:
   - **🔒 Grant access** — выдать доступ к приватным постам
   - **✅ Access granted** — нажмите ещё раз, чтобы отозвать

Доступ выдаётся **только подписчикам**: если пользователь на вас не подписан, его нет в списке — сначала он должен подписаться.

### Как это работает внутри

- Таблица `private_access(owner_id, viewer_id)` — кто кому открыл доступ
- Видимость поста определяется правилом:

```
пост виден, если:
  p.is_public = 1                                  (публичный)
  ИЛИ p.user_id = текущий пользователь             (автор)
  ИЛИ EXISTS(private_access owner=p.user_id
               AND viewer=текущий пользователь)    (выданный доступ)
  ИЛИ текущий пользователь — администратор
```

- Правило применяется в трёх местах: **лента** (`GET /api/posts/feed`), **одиночный пост** (`GET /api/posts/:id`), **профиль** (`GET /api/users/:id`)
- Гостю (без авторизации) приватные посты не видны вообще
- При отзыве доступа посты мгновенно исчезают из ленты пользователя
- Автор видит счётчик скрытых приватных постов в чужих профилях (`private_posts_count`)

### Безопасность

- Доступ выдаётся только на посты автора, который его выдал
- Никакой детекции по IP/устройству — только явная выдача
- Удаление пользователя каскадно удаляет его доступы (`ON DELETE CASCADE`)
- Приватные посты не попадают в открытые ленты, теги и поиск для посторонних

## Логотип Cosmogram

Надпись **Cosmogram** в шапке — ссылка. Клик:

- Сбрасывает фильтр ленты на **All**
- Выходит из режима просмотра одиночного поста (`/post/:id` → `/`)
- Прокручивает страницу к началу ленты
