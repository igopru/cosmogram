# Bulk Import Script Documentation

## Overview

Скрипт `import-media.js` позволяет массово импортировать фото и видео из локальной папки в ленту Cosmogram. Файлы автоматически группируются по дате создания в посты.

## Установка зависимостей

```bash
cd /opt/cosmogram
npm install
```

## Настройка

Откройте файл `scripts/import-media.js` и измените конфигурацию в объекте `CONFIG`:

```javascript
const CONFIG = {
    // Путь к папке с фото/видео для импорта
    sourceDir: '/path/to/your/photos',

    // Имя пользователя, от имени которого создавать посты
    username: 'admin',

    // Группировка по дате (в минутах)
    // 0 = каждый файл отдельный пост
    // 30 = файлы в пределах 30 минут объединяются  
    // 1440 = файлы одного дня объединяются (по умолчанию)
    groupByMinutes: 1440,

    // Фильтр по дате (опционально)
    // Оставить пустыми строками для импорта всех файлов
    dateFrom: '',  // например '2023-01-01'
    dateTo: '',    // например '2023-12-31'

    // Максимальное количество файлов за раз (0 = без лимита)
    maxFiles: 0,

    // Сухой запуск (true = только показать что будет сделано)
    dryRun: false,

    // Рекурсивно обходить подпапки
    recursive: true,
};
```

## Использование

### Базовый импорт

```bash
node scripts/import-media.js
```

### Сухой запуск (предпросмотр)

Установите `dryRun: true` в конфиге, чтобы увидеть что будет сделано без реальной загрузки:

```bash
node scripts/import-media.js
```

### Импорт с фильтром по дате

```javascript
dateFrom: '2024-01-01',
dateTo: '2024-06-30',
```

### Импорт первых 100 файлов

```javascript
maxFiles: 100,
```

### Каждый файл = отдельный пост

```javascript
groupByMinutes: 0,
```

## Как работает группировка

Скрипт читает дату создания каждого файла (EXIF для фото, дата модификации для видео) и группирует файлы:

- **groupByMinutes: 0** — Каждый файл отдельный пост
- **groupByMinutes: 30** — Файлы снятые в пределах 30 минут = один пост
- **groupByMinutes: 1440** — Файлы одного дня = один пост (рекомендуется)

Пример:
```
10:00 - photo1.jpg  ┐
10:15 - photo2.jpg  ├─ Пост 1: "3 фото — 1 января 2024 г."
10:30 - photo3.jpg  ┘

14:00 - photo4.jpg  ┐
14:20 - photo5.jpg  ├─ Пост 2: "2 фото — 1 января 2024 г."  
15:00 - video1.mp4  ┘
```

## Извлечение дат

- **JPEG**: EXIF DateTimeOriginal → CreateDate → mtime файла
- **PNG/WebP/GIF**: Дата модификации файла
- **Видео**: Дата модификации файла

## Поддерживаемые форматы

**Изображения:**
- JPEG, JPG, PNG, WebP, GIF

**Видео:**
- MP4, WebM, MOV, AVI

## Что происходит при импорте

1. Сканирует `sourceDir` (рекурсивно если `recursive: true`)
2. Для каждого файла определяет дату создания
3. Фильтрует по `dateFrom`/`dateTo` если указаны
4. Сортирует файлы по дате
5. Группирует по `groupByMinutes`
6. Для каждой группы:
   - Создаёт пост с датой первой группы
   - Копирует файлы в `uploads/images/` или `uploads/videos/`
   - Генерирует миниатюры для изображений
   - Сохраняет в БД

## Описание поста

Автоматически генерируется:
- **Одиночное фото**: `📷 1 января 2024 г.`
- **Несколько фото**: `📸 5 фото — 1 января 2024 г.`

## Troubleshooting

### "Source directory not found"
Убедитесь что путь в `sourceDir` существует:
```bash
ls -la /path/to/your/photos
```

### "User not found"
Проверьте имя пользователя в базе:
```bash
sqlite3 data/media.db "SELECT username FROM users;"
```

### Медленный импорт
- EXIF чтение быстрее чем fallback к stat
- Уменьшите `maxFiles` для тестирования
- Отключите `recursive` если не нужны подпапки

### Файлы не группируются
Проверьте даты файлов — если они сильно различаются (> groupByMinutes), каждый будет отдельным постом.

## Советы

1. **Начните с dryRun** — проверьте что всё настроено правильно
2. **Используйте maxFiles** — импортируйте небольшими порциями
3. **Резервная копия БД** — перед массовым импортом:
   ```bash
   cp data/media.db data/media.db.backup
   ```
4. **Группировка по дням** — `groupByMinutes: 1440` оптимально для архивов
