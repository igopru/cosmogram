# Preview & Thumbnail Guide

## 🖼️ Что добавлено

### 1. Превью-галерея с выбором фото
Теперь перед импортом можно:
- **Увидеть все фото** в папке в виде сетки превью
- **Исключить неудачные кадры** кликом по фото (появится ❌)
- **Выбрать только лучшие** для импорта
- **Посчитать** сколько фото будет импортировано

### 2. Скрипт генерации качественных превью
Новый скрипт `generate-thumbnails.js` создаёт превью высокого качества из оригиналов:
- **Sharp библиотека** - лучшее качество чем старые превью
- **WebP формат** - оптимальный размер при высоком качестве
- **600px ширина** - достаточно для просмотра
- **Качество 80** - хороший баланс качество/размер

## 📸 Как использовать превью-галерею

### Шаг 1: Откройте админ-панель
1. Войдите как admin
2. Нажмите ⚙️ в шапке

### Шаг 2: Выберите папку для просмотра
- Кликните на **любую папку** в списке
- Откроется превью-галерея со всеми фото

### Шаг 3: Исключите неудачные кадры
- **Кликните на фото** чтобы исключить его
- Исключённые фото показываются с ❌ и становятся полупрозрачными
- Кликните ещё раз чтобы вернуть

### Шаг 4: Массовые операции
- **✅ Select All** - выбрать все фото
- **❌ Deselect All** - снять все выделения

### Шаг 5: Импорт
- Нажмите **📥 Import Selected**
- Система создаст посты только из выбранных фото
- Исключённые фото будут пропущены

## 🔧 Скрипт генерации превью

### Базовое использование

```bash
# Сгенерировать превью для ВСЕХ папок
node scripts/generate-thumbnails.js

# Для конкретной папки
node scripts/generate-thumbnails.js --folder vacation2024

# Предпросмотр без генерации
node scripts/generate-thumbnails.js --dry-run

# Перегенерировать все (даже существующие)
node scripts/generate-thumbnails.js --force
```

### Продвинутые опции

```bash
# Указать размер
node scripts/generate-thumbnails.js --width 800

# Указать качество (0-100)
node scripts/generate-thumbnails.js --quality 90

# Комбинация
node scripts/generate-thumbnails.js --folder wedding --width 800 --quality 90 --force
```

### Параметры скрипта

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--folder, -d` | Обработать конкретную папку | Все папки |
| `--width, -w` | Ширина превью (px) | 600 |
| `--quality, -q` | Качество WebP (0-100) | 80 |
| `--force, -f` | Перегенерировать существующие | false |
| `--dry-run, -n` | Предпросмотр без генерации | false |

### Производительность

```
Пример для 1000 фото:
├── Оригиналы: ~3.2 GB
├── Превью: ~280 MB (8.7% от оригинала)
└── Время: ~2-3 минуты
```

## 🔍 API Endpoints

### Превью-сканирование
```
POST /api/admin/media/scan-preview
Body: { "folderPath": "vacation2024" }
Response: { files: [{ filename, thumbUrl, fileSize, ... }] }
```

### Получение превью
```
GET /api/admin/media/thumb/{path/to/file.jpg}
Response: WebP image (cached or generated on-the-fly)
```

### Сканирование с исключениями
```
POST /api/admin/media/scan
Body: { 
  "folderPath": "vacation2024",
  "excludedFiles": ["bad1.jpg", "blurry2.jpg"]
}
```

## 💡 Советы

### Качество превью
- Для **личного просмотра**: качество 75-80
- для **профессиональных фото**: качество 90-95
- для **экономии места**: ширина 400px

### Отбор фото
1. **Первый проход** - исключите явно неудачные
2. **Второй проход** - исключите дубликаты
3. **Третий проход** - оставьте только лучшие

### Хранение
- Превью хранятся в `/opt/media/thumbs/`
- Занимают ~10% от размера оригиналов
- Можно безопасно удалить и перегенерировать

---

## 🐛 Решение проблем

### "Preview failed"
- Проверьте что файлы существуют в `/opt/media/files/`
- Убедитесь что это поддерживаемый формат (jpg, png, webp)

### "Thumbnail not found"
- Запустите `node scripts/generate-thumbnails.js`
- Или импортирует - превью сгенерируется on-the-fly

### Медленная загрузка превью
- Превью генерируются on-the-fly если нет кэша
- Запустите скрипт для кэширования всех превью

### Ошибка при генерации
```bash
# Проверите что sharp работает
node -e "import('sharp').then(() => console.log('Sharp OK'))"

# Проверите права
ls -la /opt/media/thumbs/
```

## 📈 Статистика

После генерации превью скрипт показывает:
- **Total files** - всего обработано
- **Generated** - создано новых
- **Skipped** - уже существовали
- **Errors** - ошибки
- **Compression** - насколько превью меньше оригиналов

Пример вывода:
```
═══════════════════════════════════════════════
  Results
═══════════════════════════════════════════════
   Total files:     1234
   Generated:       1200
   Skipped:         34
   Errors:          0
   Source size:     4.2 GB
   Thumb size:      356 MB
   Compression:     8.5% of original
═══════════════════════════════════════════════
```
