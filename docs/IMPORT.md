# Импорт медиа в Cosmogram

## Кратко

Скрипт импорта работает в **две фазы**:
1. **scan** — сканирует `/opt/media/files/`, читает EXIF-даты, сохраняет очередь в БД
2. **import** — читает очередь, создаёт посты, копирует файлы

## Ключевые параметры

| Параметр | Значение | Описание |
|---|---|---|
| `sourceDir` | `/opt/media/files/` | Источник медиафайлов |
| `thumbSourceDir` | `/opt/media/thumbs/` | Готовые миниатюры (для изображений) |
| `batchSize` | `20` | Макс. файлов в одном посте |
| `groupByMinutes` | `1440` | Группировка по дате (24 часа) |
| `username` | `admin` | Пользователь, от которого создаются посты |

## Как работает

### Фаза 1: Scan
```bash
node scripts/import-media.js scan
```
- Рекурсивно сканирует `sourceDir`
- Для каждого файла читает EXIF дату (или fallback к mtime)
- **Запоминает папку** — файлы из разных папок НИКОГДА не объединяются
- Сохраняет в таблицу `import_queue` с датой, типом, размером, путём папки
- **Память**: файлы пишутся в БД сразу при обходе, без накопления в памяти
- Прогресс: каждые 1000 файлов

### Фаза 2: Import
```bash
node scripts/import-media.js import
```
- Берёт файлы из `import_queue`, **группируя по папкам**
- Внутри каждой папки группирует по дате (в пределах `groupByMinutes`)
- **Файлы из разных папок никогда не попадают в один пост**
- **Максимум 20 файлов на пост**
- Для **изображений**: копирует `.thumb.webp` из `thumbSourceDir` (~8KB)
- Для **видео**: создаёт **симлинк** на оригинал в `sourceDir` (мгновенно)
- Создаёт посты с описанием вида `📸 20 фото — [папка] 7 июня 2025 г.`

## Группировка файлов

### По папкам
Каждая папка в источнике обрабатывается **независимо**:
```
/opt/media/files/
├── 2024-01/        → отдельные посты
├── 2024-02/        → отдельные посты
└── vacation/       → отдельные посты
```

### По времени внутри папки
Файлы одной папки группируются по дате:
| `groupByMinutes` | Поведение |
|---|---|
| `0` | Каждый файл = отдельный пост |
| `30` | Файлы в пределах 30 мин = один пост |
| `1440` | Файлы одного дня = один пост ✅ |

### Пример
```
папка: 2024-01
  10:00 - photo1.jpg  ┐
  10:15 - photo2.jpg  ├─ Пост 1: "📸 [2024-01] 3 фото — 1 января 2024 г."
  10:30 - photo3.jpg  ┘

  14:00 - photo4.jpg  ┐
  14:20 - photo5.jpg  ├─ Пост 2: "📸 [2024-01] 2 фото — 1 января 2024 г."
  15:00 - video1.mp4  ┘

папка: 2024-02
  09:00 - photo6.jpg  ┐
  09:10 - photo7.jpg  ├─ Пост 3: "📸 [2024-02] 2 фото — 2 февраля 2024 г."
                      ┘
```

## Очистка и повторный запуск

```bash
# Полный сброс (посты + медиа + файлы + очередь)
node scripts/import-media.js reset

# Или по шагам:
# 1. Очистить очередь
node scripts/import-media.js clear

# 2. Очистить uploads
rm -rf uploads/images/* uploads/videos/* uploads/thumbnails/*

# 3. Перезапустить с нуля
node scripts/import-media.js scan
node scripts/import-media.js import
```

## Мониторинг прогресса

```bash
# Статус очереди
node scripts/import-media.js status

# Или напрямую в БД
sqlite3 data/media.db "
    SELECT
        (SELECT COUNT(*) FROM posts) as posts,
        (SELECT COUNT(*) FROM import_queue WHERE status='done') as done,
        (SELECT COUNT(*) FROM import_queue WHERE status='pending') as pending,
        (SELECT COUNT(*) FROM import_queue WHERE status='error') as errors,
        (SELECT COUNT(DISTINCT folder_path) FROM import_queue) as folders;
"

# Файлы на диске
ls uploads/images/ | wc -l   # изображений
ls uploads/videos/ | wc -l   # видео
```

## Важные детали

1. **Папки изолированы** — файлы из разных папок NEVER объединяются в один пост
2. **Изображения** — используются **миниатюры** (~8KB), а не оригиналы (~7MB)
3. **Видео** — **симлинки** на оригиналы в `/opt/media/files/`. Мгновенно, без копирования
4. **Синхронность** — скрипт полностью последовательный, без async
5. **Ограничение памяти** — scan пишет файлы в БД сразу при обходе дерева (batch по 500)
6. **Запуск** — для больших библиотек запускать через `timeout` в несколько раундов:
   ```bash
   timeout 180 node scripts/import-media.js import
   # Повторять пока pending != 0
   ```

## Команды скрипта

| Команда | Описание |
|---|---|
| `scan` | Сканировать файлы, сохранить в очередь |
| `import` | Импортировать из очереди (создать посты) |
| `status` | Показать статус очереди |
| `clear` | Очистить очередь |
| `reset` | Сбросить все посты и медиа (пользователи сохраняются) |
